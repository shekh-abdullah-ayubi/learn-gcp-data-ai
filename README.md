## 🗺️ GCP Resource Map

This repository categorizes Google Cloud services into logical, actionable layers to help you choose the right tool for the job.

### 🧠 1. AI & Machine Learning
*   **Vertex AI**: The unified platform for training, deploying, and monitoring custom ML models and orchestrating MLOps pipelines.
*   **Vertex AI Studio**: Hands-on prototyping with Foundation Models (Gemini), prompt engineering, and tuning.
*   **BigQuery ML**: Build and execute machine learning models directly inside BigQuery using standard SQL.

### 🗄️ 2. Data Warehousing & Analytics
*   **BigQuery**: Serverless, highly scalable enterprise data warehouse with built-in BI and machine learning capabilities.
*   **Dataproc**: Managed Apache Spark and Apache Hadoop clusters for legacy big data migration and heavy batch processing.
*   **Dataplex**: Intelligent data fabric to unify, govern, and monitor data distributed across data lakes and warehouses.

### 🌊 3. Data Integration & Streaming
*   **Pub/Sub**: Asynchronous, many-to-many messaging service for real-time streaming analytics and event-driven architectures.
*   **Dataflow**: Unified, serverless stream and batch data processing based on Apache Beam.
*   **Cloud Data Fusion**: Fully managed, cloud-native data integration service for visually building ETL/ELT pipelines.
